# Digital Store 👟

Projeto de loja virtual desenvolvido com React e Vite como parte do projeto acadêmico da Digital College.

## 📌 Sobre o projeto

A Digital Store é uma loja virtual de calçados que permite aos usuários navegar pelo catálogo, pesquisar produtos, aplicar filtros e visualizar detalhes individuais de cada tênis.

## 🚀 Tecnologias utilizadas

- React
- JavaScript
- Vite
- CSS
- React Router DOM

## ✨ Funcionalidades

- Página inicial com banners e coleções em destaque.
- Catálogo de tênis.
- Pesquisa de produtos com suporte a buscas sem acentuação.
- Filtros por categoria, marca e condição.
- Ordenação por preço.
- Página individual para cada produto.
- Galeria de imagens dos produtos.
- Seleção de tamanhos e cores.
- Seção de produtos recomendados.
- Layout responsivo para diferentes tamanhos de tela.

## ⚙️ Como executar o projeto

1. Clone o repositório:

```bash
git clone https://github.com/JoseGabrielSA/Digital-Store.git
```

2. Entre na pasta:

```bash
cd Digital-Store
```

3. Instale as dependências:

```bash
npm install
```

4. Inicie o projeto:

```bash
npm run dev
```

5. Abra no navegador o endereço indicado pelo Vite, geralmente `http://localhost:5173/`.

## 🛍️ Demonstração

O projeto apresenta uma experiência de navegação por produtos, com visualização de detalhes, seleção de opções e pesquisa no catálogo.

> A funcionalidade de compra é demonstrativa e não realiza pagamentos ou pedidos reais.
